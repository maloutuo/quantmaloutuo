# 截图存放说明

README 引用以下 4 张图，请把工作台网页的截图按文件名放进来（PNG，建议宽度 ≥1600px，深色/浅色主题保持一致）：

| 文件名 | 截什么 | 要点 |
|---|---|---|
| `01-cases.png` | 监管案例库 Tab | 展开一个案例，让**法规条款锚点（紫）/ 案例原文 / 案例法锚点（红）/ 自查启示（黄）**四块同屏可见 |
| `02-qa.png` | 合规问答库 Tab | 搜一个具体问题（如「冷静期」），显示命中高亮与三段式正文 |
| `03-policy.png` | 制度生成器 Tab | 输入组织架构后的结果页，能看到【依据】【原文】脚注与「需补建部门」提示 |
| `04-perf.png` | 绩效分析 Tab | 净值曲线 + 指标卡片 + 月度热力图 |

截图前请先脱敏：

- 把机构名称、产品名称、投资者姓名替换为示例值；
- 不要在截图里露出本地文件路径、浏览器书签栏、其他业务窗口；
- 案例库截图建议选**已公开的监管处罚案例**（本就是公开信息），避免用自家产品的处罚记录。

截好后可选：用 `pngquant`/`oxipng` 压一下，单张控制在 400 KB 以内。
