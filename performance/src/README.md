# 绩效分析平台

导入 Excel / CSV 净值数据，自动计算收益、风险与风险调整收益指标，并支持**多产品共轨区间对比**。
全部计算在浏览器本地完成，数据不会上传。指标口径参考 ARGOS 绩效分析体系。

## 快速开始

- **双击 `绩效分析平台.html`** 即可使用（单文件、离线可用，无需服务器）
- 或解压后用浏览器打开 `dist/index.html`
- 开发调试：`npm install` → `npm run dev`

## 三大页面

| 页面 | 能力 |
|---|---|
| 数据导入 | Excel / CSV / **ZIP 压缩包** / 粘贴解析、多工作表选择、版面自动识别与人工校正、基金产品名称自动识别、产品列表管理 |
| 单产品分析 | 收益 / 风险 / 风险调整 / 胜率四类指标卡、净值走势、回撤曲线、月度收益热力图、相对基准指标 |
| 多产品对比 | 净值口径切换（单位 / 累计 / 复权）、日期区间选择、共轨区间指标对比表、净值归一化曲线、相关性矩阵、月度收益对比、相对基准指标、CSV 导出 |

## 对比窗口：净值口径 + 日期区间

多产品对比页顶部可同时控制两件事，切换后**共轨区间内所有指标（收益、风险、相关性、月度）都按新窗口重算**：

- **净值口径**：单位净值 / 累计净值 / 复权净值
  - 单位净值：分红当日会回落，含分红的产品会被**低估**（分红未再投资）
  - 累计净值：单位净值 + 累计单位分红，不再回落，但仍未计入分红再投资收益
  - 复权净值（默认）：按导入页所选复权口径还原，分红再投资，指标计算默认用这条
- **日期区间**：起止日期输入（自动以可用范围为 min/max），外加「近 1 月 / 3 月 / 6 月 / 1 年 / 3 年 / 今年以来」快捷按钮
  - 区间先裁剪各序列再求交集，所以对比窗口**完全由人工区间决定**，不再受某条序列的起止日期限制
  - 区间内共同日期不足 2 个时给出提示，可一键恢复全部区间

## 压缩包导入

直接把 `.zip` 拖进导入区即可，**包内每个 Excel / CSV 各成一个数据源**，可逐个切换预览：

- **嵌套 zip** 自动递归展开（最多 3 层），适配「外层包套 N 个月度内层包」的托管导出；
  条目名保留层级，形如 `月度汇总.zip › 2026-07估值表.xls`
- **文件名编码**：UTF-8 标志位优先，未置位时回退 GBK（WinRAR / 360压缩 常见）
- **解压实现**：浏览器原生 `DecompressionStream('deflate-raw')`，不引入第三方依赖；
  支持存储（method 0）与 Deflate（method 8）。加密、分卷、ZIP64 会明确报错而非静默给空数据
- 包内非表格文件（PDF / 图片）与 `__MACOSX`、隐藏文件自动跳过
- 单个坏条目解析失败不影响其余文件
- **`.xlsx` / `.xlsm` 本身也是 ZIP 归档**：导入时不按容器解包，而是直接作为工作簿解析；若误判为压缩包且包内无可识别表格，会自动回退按整包解析，避免把真正的 Excel 误报成「空压缩包」

## Excel 解析能力

- **多工作表**：一次读取全部 sheet，可逐个切换预览
- **版面识别**：自动定位表头行（可跳过文件标题行）、日期列、数值列
  - 纵向（日期在列）——国内导出最常见
  - 横向（日期在行、产品名在首列）
- **人工校正**：识别不准时可手动切换版面、表头行、日期列
- **多产品一次导入**：宽表里每一列作为一条产品序列
- **智能合并**：选中「单位净值 + 累计净值」两列时自动合并为一个产品
- **收益率序列**：含百分号的列自动识别为日收益率并累乘还原为净值
- **日期格式**：`2024-01-02` / `2024/1/2` / `2024年1月2日` / `20240102` / `1/2/24` / Excel 日期序列号 / 带时间戳文本
- **数值格式**：千分位、全角数字、百分号、货币符号、括号负数；`-` `—` `N/A` 等按空值处理
- **编码**：CSV 自动 UTF-8，失败回退 GBK（国内券商 / 托管导出常见）

## 复权净值

同时导入「单位净值 + 累计净值」两列时，平台依据恒等式

```
累计净值 − 单位净值 = 累计单位分红
```

反推区间内的**分红**与**份额拆分**，并按所选口径还原复权净值：

| 口径 | 说明 |
|---|---|
| **复利复权（默认）** | 公司口径：`复权净值(t) = 单位净值(t) × ∏(分红前单位净值 ÷ 分红后单位净值)`，见下方公式 |
| 向后复权 | ARGOS 口径：以期初单位净值为锚向后累乘全收益率，期末净值＝真实累计回报 |
| 向前复权 | ARGOS 口径：以期末单位净值为锚向前折算，历史净值压缩到当前份额口径 |
| 不复权 | 直接采用累计净值。分红后累计净值被当作收益分母，会**低估**分红再投资收益 |

### 复利复权公式

```
复权净值(t) = 单位净值(t) × ∏ [ 分红前单位净值(s) ÷ 分红后单位净值(s) ]      s ≤ t

其中：
  分红前单位净值 = 除息日前一交易日的单位净值
  分红后单位净值 = 分红前单位净值 − 单位分红金额
  份额拆分：连乘拆分因子 k（如 1 份拆 2 份则 k = 2）
```

### 向后 / 向前复权公式（ARGOS）

全收益率（分红再投资、并修正份额拆分）：

```
r_t = [ (单位净值_t + 单位分红_t) × 拆分因子_t ] / 单位净值_{t−1} − 1
```

要点：
- **复利复权 vs 向后复权**：差别不在于"是否复权"，而在于**分红按什么价格再投资**
  - 复利复权：按除息后、当日损益前的净值再投资
  - 向后复权：按当日收盘净值再投资
  - 本平台除息约定为「先除息、后计当日损益」，故复利复权 ≥ 向后复权；
    若数据源约定相反（先计损益、后除息），两者高低关系对调
- 向后复权与向前复权的**收益率序列完全相同**，仅净值基准不同，因此除「期末净值」外所有指标一致
- 真正影响收益高低的是**是否复权**：有分红时复权口径高于不复权口径
- 识别出的分红 / 拆分事件会在导入页逐条列出，可人工「忽略」误判后重算
- 拆分判定需同时满足「单位净值与累计净值同比例跳变」与「比例接近常见拆分比（1:2、1:3、1:10…）」，
  避免把单日大跌误判为份额拆分

## 产品名识别

托管 / 服务机构导出的文件名通常是
`SY0001_示例稳健一号私募证券投资基金_20260201新规_纳税申报表_1791448635252.xls`，
直接当产品名又长又像乱码。平台按下述顺序推导：

1. **表内容优先**：扫描前 20 行找「产品名称 / 基金名称 / 产品代码」表头，取其下第一个非空值；
   表头不规范时全表搜索符合基金命名规则的字符串
2. **文件名兜底**：正则提取全称；再退一步按 `_ - 空格` 切段，剔除产品代码、8 位日期、
   13 位时间戳、`2026Q4` 这类季度标记与文档类型词（纳税申报表 / 估值表 / 月报 / 年报 …）
3. **简称生成**：全称去掉基金类型后缀（私募证券投资基金…）与基金管理人字号
   （字号从「纳税人名称 / 基金管理人」反推，默认含「示例」），得到 **稳健一号** 这类可显示名

导入页在解析预览处直接显示 `识别产品：稳健一号 SY0001`；产品列表里简称可就地编辑，
全称与代码以小字附在下方，鼠标悬停可见完整信息。

少数老导出会把 UTF-8 字节按单字节解码（`è·ƒå¨ä¸€å·`），解析时会做一次还原兜底。

## 指标口径

- 收益率基于**复权净值**（不复权口径下即累计净值）
- 年化收益率支持两种口径，可在导入页切换：
  - 自然日 365 天几何年化（默认）
  - 交易日 252 天（ARGOS 口径）：`(1+R)^(252/T) − 1`
- 波动率 / 夏普 / 索提诺按交易日 √252 年化
- 无风险利率默认 1.5%，可调整后实时重算
- 多产品对比在**共轨区间**（各产品日期区间交集）内重算全部指标，缺失日期按上一有效净值填充，保证横向可比

### 指标清单

- 收益：区间收益率、年化收益率、最新累计净值
- 风险：年化波动率、下行波动率、最大回撤（含起止与修复日）、年化 VaR95、收益偏度
- 风险调整：夏普、索提诺、卡玛
- 胜率：日胜率、月度胜率、盈亏比
- 相对基准：年化超额（算术 / 几何）、跟踪误差、信息比率、Beta、Jensen Alpha、特雷诺、相关系数、日度相对胜率、相对盈亏比、上行捕获率、下行捕获率、基准最大回撤

## 图表日期轴

X 轴一律用真实日期（tooltip 悬停始终显示完整 `yyyy-mm-dd`），刻度按区间跨度自动缩短：

| 区间跨度 | 刻度格式 |
|---|---|
| ≤ 4 个月 | `MM-DD` |
| ≤ 2 年 | `YY-MM` |
| > 2 年 | `YYYY-MM` |

刻度密度按点数控制在 10 个左右，避免长区间标签重叠。
