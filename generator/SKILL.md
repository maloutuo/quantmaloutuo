# 私募证券基金管理人内控制度生成器

## 解决什么问题

为私募证券投资基金管理人生成**可直接落地、可被监管查证**的内控制度。

三条硬标准：
1. **精简** —— 不写套话、不铺陈，一条只解决一个控制点。每条正文 ≤ 200 字，写清"谁—做什么—留什么痕"。
2. **符合规章** —— 每条对应现行有效法规，不引用已废止文件。
3. **每条有出处** —— 脚注式：条款正下方标【依据】《法规》第X条，再给出【原文】全文。

## 核心原则（不可违反）

### 一、先核对，再落笔
**绝不允许凭记忆写条款号。** 生成前必须读 `references/01-法规原文库.md` 核对条号与原文。某条不在库中时：联网取官方原文（优先 gov.cn、csrc.gov.cn、amac.org.cn）→ 核对 → 落脚注；无法核实的**必须标注"⚠️ 待核实"**，禁止编造条号。

### 二、法规效力层级（冲突时上位法优先）
1. 法律：《证券投资基金法》《信托法》《公司法》《合伙企业法》
2. 行政法规：《私募投资基金监督管理条例》（国务院令第762号，2023-09-01 施行）
3. 部门规章：《私募投资基金监督管理暂行办法》（证监会令第105号）、《证券期货投资者适当性管理办法》（证监会令第130号）
4. 自律规则：《私募投资基金管理人内部控制指引》《私募投资基金登记备案办法》《私募基金管理人登记指引第1号》《私募证券投资基金运作指引》

### 三、组织架构驱动，不做无差别套模板
缺项要问，不要默认：部门设置与职责、关键岗位与人数（合规风控负责人、投资经理、交易员、高管人数）、管理规模区间、是否委托募集 / 外包（信息技术、会计核算）/ 基金是否托管、是否集团化。

### 四、精简标准
一条只解决一个控制点；能落地才写；不写"应当加强""高度重视"这类无执行内容的套话。

## 工作流

### 第 0 步：合规校验（必做）
```bash
python scripts/intake_check.py --json <组织架构.json>   # 或按提示交互输入
```
输出四类结论：**错误**（阻断，必须先解决）、**警告**（应补建部门/人数）、**风险**（法律冲突点）、**待确认**。同时给出应生成的模块清单。

### 第 1 步：确认输入
按 `templates/组织架构输入.json` 收集；自然语言输入时按 `references/03` 的引导补齐。

### 第 2 步：模块选型
依据 `references/02-制度模块与法规映射表.md`：必建模块无条件生成；触发模块按业务安排（托管/委托募集/外包/场外衍生品/债券/程序化/自有资金/集团化）决定；选建模块询问确认。

### 第 3 步：逐条撰写
每条先查原文 → 落正文 → 落脚注。`references/09-制度条款库.json` 提供条款骨架与引用，占位符按实际部门名填充（不凭空造部门）。

### 第 4 步：自检
- [ ] 每条引用是否都能取到原文（取不到即标红 ⚠️）
- [ ] 条号与原文是否逐字一致
- [ ] 是否存在套话
- [ ] 部门/岗位名称是否与输入一致
- [ ] 脚本选出的模块是否全部生成

自检不通过不发稿。

### 第 5 步：输出
默认 Markdown；用户要 Word 时转 .docx。结构：制度正文（含脚注）+ 文末《法规依据索引表》+ 待确认事项。

## 网页工具（主交付入口）

每次改动 `references/` 后必须重新构建：

```bash
python scripts/build_platform.py      # 构建产物
python scripts/check_platform.py      # 冒烟校验（JSON 可解析 + JS 语法 + 条文抽样）
```

产物：`output/私募证券基金管理人内控制度生成器.html` —— 单文件，双击即开，无需服务器、无需联网。

**功能**：
1. 极简输入：公司名 + 部门人数（可增删行，一键"按标准架构填充"）
2. 组织架构诊断：严重 / 提示 / 符合三档结论，每条带法规依据可点开看原文；附「职能配置对照表」（建议 vs 现状，含建议人数与依据）
3. 制度生成：按架构自动勾选模块（36 个），一键生成带【依据】+【原文】脚注的制度全文，可复制 / 下载 .md
4. 法规原文库：186 条条文全文检索

**数据源（唯一事实来源，构建时自动解析，不在脚本内重写任何原文）**

| 源文件 | 解析出 |
|---|---|
| `references/01-法规原文库.md` | 内控指引 33 条、登记备案办法 3 条、登记指引1号 3 条 |
| `references/05-运作指引全文.md` | 运作指引 42 条（2024-08-01 施行） |
| `references/06-适当性办法全文.md` | 适当性办法 43 条 |
| `references/07-私募条例全文.md` | 私募条例 62 条（官方源） |
| `references/09-制度条款库.json` | 36 个模块的条款与引用 |

构建时做**引用完整性校验**：任何条款引用取不到原文，构建器会列出并在页面上把该条脚注标红 ⚠️。**校验不通过不得交付。**

## 已知法律冲突（必须按此处理）

| 事项 | 冲突 | 处理 |
|---|---|---|
| 委托募集 | 《私募条例》第十七条要求自行募集 vs《内控指引》第十七条允许委托 | **上位法优先**，默认按自行募集写；违反罚则 10 万–100 万元 |
| 适当性错配 | 《运作指引》第五条禁止 vs《适当性办法》第十九条允许跨级+书面警示 | 取严者：**禁止错配** |
| 保存期限 | 内控资料 10 年 vs 适当性资料 20 年 | 分列：内控资料 ≥10 年，适当性资料 ≥20 年 |

## 已知边界（务必告知用户）

1. 生成结果是**制度草案**，须经合规风控负责人审核、最高权力机构审议通过后生效（《内控指引》第三条：最高权力机构对建立内控制度和维持其有效性承担最终责任）。
2. 法规会更新。原文库标注核对日期（见 `01` 维护记录），超 6 个月须重新核对。
3. 本工具输出为**基于已核对法规原文的条款汇编**，不等于法律意见；涉具体争议应咨询专业律师。
